# Audio asset manifest

All WAV files are generated on-device by `AudioSynthesizer.kt` using deterministic original synthesis code. The app bundles no third-party recordings. The generated WAVs have no third-party asset licence or attribution requirement.

| Scene | Generated loops | Generated events |
| --- | --- | --- |
| Rainy Room | Window rain, room tone, distant traffic | Window droplets, far thunder |
| Night Train | Carriage hum, rail rhythm, night wind | Tunnels, passing trains |
| Forest Cabin | Fire, roof rain, forest wind | Timber creaks, distant owl |

Any future recording should have its source, author, licence, attribution text, and edits recorded here before distribution.
